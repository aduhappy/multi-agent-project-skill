## 5. 铁律 / 约定（违反会出错或返工）

> 本节记**行为约束**（能不能做），不记文件放哪--文件位置见 5.5 节。两节不重叠：
> - 5 节 = 行为红线（不改原始数据/不静默改参数/不分进程绘图/口径不混用）
> - 5.5 节 = 路径纪律（大文件去哪、小产物回哪、不往云同步盘塞 GB 级中间件）
> - 判据：铁律约束"能不能做"，路径约定约束"做了放哪"。
- **不可混用的维度**（硬约束）【待填：列出本领域绝对不能混用的维度。例：53µm 粒径法 ≠ 密度法/氧化法；g/kg ≠ Mg/ha（差 1000 倍）；Albers 投影 ≠ WGS84 坐标；表层(0-20cm) ≠ 深层(20-40cm) 不可合并回归；不同时期的数据不可混为同一期】
- 【待填：环境调用规矩。例：绘图用 base env，栅格用 X env，二者不可同进程（DLL 冲突）】
- 【待填：数据规矩。例：离散数据重采样必须 near/mode，绝不双线性/三次】
- 【待填：口径/单位规矩。例：组分数据以 53µm 粒径法为主干，密度法/氧化法不混入主干回归】
- 【待填：命名规矩。例：中文图含 ²/µ 用 mathtext（$^2$/$\mu$），SimHei 缺字形会显方框】
- 【待填：跨数据集去重规则。例：按 DOI + 坐标(±0.01°) + 数值近似 去重】
- **代码归位**：脚本进 `scripts/`，不散落根目录。每新增一个脚本，同步更新 `scripts/README.md`（写清这个脚本干嘛、输入、输出、谁写的）。根目录只放入口文件和薄指针。
- **收工规矩**：每个 agent 结束时更新本文件 §3（累计快照，带日期）+ §4 看板 + 写/更新 `STATUS.md`（**增量 handoff**：本轮做了什么/动了哪些文件/踩了什么坑，不重复 §3）。收工时跑 `python scripts/check_handoff.py` 自检——验证 §3 日期新鲜、TL;DR 已填、STATUS.md 非模板、薄指针存在。全过才算交接合格。
- **独立复核分级阀门**：产物类型决定复核深度--
  - 纯文本/格式类（写作、格式转换）：自检够。
  - **分析建模/参数选定**（模型拟合、调优、样本集清洗）：**必须独立复核**--另一 agent 或主控抽验关键数字（守恒/边界/格数/量级/各文档一致性），通过才算完成。
  - **论文结论/头条数字**（端点均值、百分比变化、方向判定）：**必须独立复核**（复核人不同）。
  - "自检全过"不构成通过判据。独立复核通过前，产物标记为"待验，下游不得启用"。不确定时走完整流程。
  - 🔴 **复核方的结论同样要可证伪**：复核方用单一来源下的断言、凭记忆写的数字、未实测的推测，**不因为出自复核方就更可信**。
  - 🔴 **执行方有权停下来质疑任务卡，质疑本身不计为失败**——出卡方也会错，没有哪一方不可质疑。
- 🔴 **开跑先自证身份**（多树 / 迁移 / 克隆场景必做）：**第一条动作**先跑并贴出
  `git rev-parse --show-toplevel`，与任务卡写明的**仓库根完整绝对路径**比对，
  不一致**立刻停下报告，不许继续**。
  🔴 **判据只有这一条。不要用 HEAD sha 当标识**——HEAD 在 clone 之间**相同**（会放行错误的树），
  又随正常提交**变化**（会拒绝正确的树）；**也不要用 HEAD 黑名单**（「HEAD 不得等于 X」）——
  两棵树停在同一 commit 时（刚 clone/复制完最常见）会把**正确的树**一起拦掉。
  🔴「当前目录是一个有效仓」≠「它是本任务指定的那棵树」——旧 clone 可以有相同 remote、
  相同分支、相同 `AGENTS.md`，光验「是不是仓」拦不住。
  📌 **已知代价**：在役树**合法迁移**时路径会变，本判据会在**正确的树**上失败——
  这是**权衡不是解决**（迁移罕见、clone 混淆常见）。
  🔴 **所以迁移后必须做三件事**（缺一，下一个 agent 就会被正确的判据拦在正确的树外面）：
    **①【更新在途任务卡的路径判据】** —— 谁做：**执行迁移的那个 agent**（不是下一个）。
    怎么找全：任务卡索引里状态为「待派发 / 进行中 / 待复核」的**全部**卡，逐张改。
    完成证据：🔴 **不是「全树命中为 0」**——历史报告、归档、只读副本、第三方依赖里留有旧路径是**正常且无害**的，全树永远归不了零（本课题实测残留 78 处命中）。**判据限定在「活动执行面」，而这个面必须是【算出来的闭集】、不是【圈出来的目录】**：🔴 **入口** = 验收编排器 / 构建脚本里**实际被调用**的那些文件（从编排器源码里机器提取，别手写清单）；🔴 **面** = 从入口出发，沿 `import` 与 `subprocess` 调用**递归展开的传递闭包**。**该面内命中为 0**；报告里要给出**闭包是怎么算出来的**（入口从哪来、展开到第几层）。🔴 **不许用目录名圈定**（「`scripts/` 算、`outputs/` 不算」这种）——目录既会漏（打包产物里的脚本副本、动态 import 的模块）也会多（同目录下的废弃文件）。面外命中列成**旧路径清单**附在报告里，并写明每条为何无害。🔴 **别忘了仓库之外**：agent/工具的配置里也会写死项目路径（可写根、trusted 项目列表、IDE 工作区、定时任务）。**迁移后不更新这些，下一个 agent 会在正确的树里被自己的工具拦住**——本技能作者实测撞过：复审 agent 连着两轮交不出报告，根因就是它的 trusted 列表里没有新位置。
    **②【在新位置重跑验收确认恢复】** —— 跑**哪一套**：迁移前那一次的**同一套门、同一个编排入口、
    同一个解释器**（版本写进报告）。判据：🔴 **只比 rc 不够**——退出码相同而产物错了的情况真实存在。
    除逐门 rc 一致外，还要对照**关键产物的哈希**与**各门的汇总行**。🔴 **「关键产物」不许人工挑**——取**构建/发布 manifest 里登记的那一组**（没有 manifest 就先建一个：产物路径 + 哈希 + 产出它的门）；**汇总行**取**门自己打印的那一行**（如 `12/12`），不许转述。🔴 人工挑会退化成「挑几个好看的对一对」，和只比 rc 差不了多少。任何一项对不上都要解释，不许因为 rc 绿就放行。
    证据：新旧两份 summary + 关键产物指纹一并留档。
    **③【旧树留一份指向新位置的标记】** —— 🔴 **它的用途是【导航与审计】，不是拦截**：
    给**人**看的线索、事后追溯的凭据。**不要指望它挡住 agent**——
    本条前半段已论证被动标记拦不住（实测：agent 读到「勿用」、还在报告里引用了，
    然后照样在那棵树里干了一整轮；后来又有工具在挂着标记的树里写入了文件）。
    **拦截只靠 ① 的路径判据。**

- 🔴 **关键测量双源交叉**：会推翻结论、触发删除/迁移、或决定验收数的**测量**，必须用两种失效模式不同的方法各测一次，写明被测量量定义、两个来源、容差、裁决方式。🔴 **两源不一致 → 记 `UNKNOWN`、停下游、禁止投票、禁止静默挑一个。** 🔴 **两源在容差内一致、却分别落在验收阈值两侧（一个判过一个判不过）→ 同样记 `UNKNOWN` 并停**——「测量一致」不等于「结论一致」。分歧首先说明「语义没钉住」，不是「哪个工具对」。
- **关键数字单一来源**：同一数字（均值/百分比/面积/统计量等）只在 STATUS.md 或 AGENTS.md §3 一处写定，别处引用不复述。收工前核对所有文档间数字一致性——同一数字在不同文档差 1% 以上即视为 bug，必须对齐才能交。
- **坏产物退役隔离**：发现某 agent 产物错了，立即做四件事：① 目录/文件名加 `_DEPRECATED` 后缀或移入 `_作废/` 子目录；② 在 §5（铁律节）顶部用红字 `> ⚠️ 【作废】<路径> <原因>` 标注（别标在 §3——§3 是累计快照，坏产物标记应和铁律/规范同在 §5）；③ 更新 §4 看板状态为 `[x]` + 标注"作废"；④ 更新 STATUS.md 反映作废。绝不只靠记忆说"那个别用"。

## 5.5 路径约定（重要：避免云同步爆炸 / 多 agent 撞车）

> 本节记文件的**物理位置约束**（大文件去哪、小产物回哪），不记"能不能做"。行为约束见 5 节。
项目根 `【待填：绝对路径】` 在【待填：是否云同步目录，如 OneDrive】里【会/不会】自动同步。大量/大体积/中间文件**绝不能**直接写进项目根，否则同步卡死。

| 目录 | 用途 |
|---|---|
| `<项目根>\` | 小产物（KB–几 MB 的 CSV、PNG、脚本、md、最终少量栅格）|
| `【待填：工作盘如 D:\scratch 或 /mnt/scratch】\` | 大体积/中间件（GB 级 RF 中间栅格、整包，绝不进项目）|
| `【待填：临时目录】\` | 通用临时 |

- **判据**：单个 >50MB 或一次产 >十几个文件 → 进 scratch；小文件进项目。
- 脚本里**输出路径写成常量置顶**（如 `SCRATCH=r'F:\xxx_scratch'`、`PROJ_OUT=r'...\output'`），方便核查与改盘。
- 原始数据源（Zotero/手动下载源数据）**只读，勿写勿删**。
