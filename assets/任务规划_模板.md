# T1 <用大白话写的任务名：做什么、为了回答什么>

## 进度回写（执行方、复核方只改这一节；其余只读）

- 状态：⬜可派
- 执行方：工具【】/ 模型【】/ 家族【】/ 开工【】/ 交回【】；产物【】；一句话结果【】；偏离或疑点【】
- 复核方：工具【】/ 模型【】/ 家族【】/ 日期【】；结论【】；报告【】
- 主控收口：【D-xx，日期；一两句结论，细节进 STATUS 与决策记录】

> 状态：🟠待裁定（不可派）/ ⬜可派 / ⏳执行中 / 🟡待复核 / 🔵待收口 / ✅已收口 / ⛔退回 / 🗄️作废。**只有 ⬜ 可派。**谁改哪里、🔒 节怎么补、何时开新卡、卡多大要拆，只看 `文档/任务卡_README.md`“卡面规矩”。
> 家族按模型名写（GPT→OpenAI、Claude→Anthropic、GLM→智谱、DeepSeek→DeepSeek 等），连模型名都不知道才写 UNKNOWN；不从工具名猜。UNKNOWN 不算通过。
>
> 范围：【一句话写清范围和边界（D-xx，YYYY-MM-DD 建卡）。核查类卡写“全部 X”，不替复核方划范围。】自由度：【写死／目标＋底线，见 `文档/任务卡_README.md`“自由度”】
> 每张卡**自包含**：零上下文 agent 读本卡 + 线级 `AGENTS.md`/`STATUS.md` + 卡内列出的输入即可开工，不依赖聊天记录。一个任务一张卡，执行和独立复核同卡。

## 大白话：为什么要做

【3—6 句：现在卡在哪、这张卡要回答什么、结果拿去干什么。读者是用户本人，不用术语堆砌。】
【和已有工作的关系先写清：哪些不是本卡首创，本卡不同在哪。没有就删掉这段。】

## 主控在立项前看过什么（照实写；复核方冷读阶段不读本节）

【主控只读探查过什么、没算过什么；主控对命中范围的初步判断只能写在本节，不写进目标或提示词。】
【卡面每个数字都注明出处（脚本/文件 + 口径）；没核过的标“主控估算”。执行方开工先核对，对不上就停。】

## 已经定了的事

- 【引用决策登记表的 ID，例：研究区按 D-xx；主规则按 D-yy。不在卡里重抄决策内容。】
- 【本卡沿用的上游产物版本。】

## 输入（开工先核对；实质对不上就停，程序性出入记“偏离”）

| 文件 | 核对方式 |
|:--|:--|
| 【路径】 | 【SHA-256 期望值 / 行数 / 要点数】 |

- 其余只读输入：【路径；列名、编码、单位等读法要点】
- 哈希只记判据依赖的对象（声称未改的输入、交付物），开工、收尾各算一次比对；不给每份日志逐个记。

## 闸门（不过就停）

1. 【能复现的基准：例，抽 10 条用另一种方法算，差 ≤ 容差】
2. 【规模核对：例，行数/要素数与上游一致】
3. 【查交付物本身：落盘后重新打开最终交付文件本身，用脚本核对页数/行列数、关键文字、图片数或字体；导出图与运行日志不算】

## 🔒 写死的定义与判据（结果出来前写死，不因结果改动）

- 【定义：每个量怎么算，含边界情况怎么处理】
- 【说法/判据：怎样算成立、阈值、种子、分层、读法】
- 【没有判断要做的纯整理任务，写“口径”即可，删掉“说法”】
- [ ] 模拟／检验类卡派出前主控自查（别的卡删掉这三行）：效应方向与预期一致——把“参数＞0 时会怎样”的句子和式子符号对一遍
- [ ] 随机种子不跨格重叠（例：格序号×1000＋第几次，不用“格序号＋第几次”）
- [ ] 闸门里有“复现已有结果”一条

## 另报（描述，不立说法）

【只描述不判的附表。没有就删。】

## 🔒 措辞

【禁止的说法 → 可用的说法，成对写（做法见任务卡索引）；要写进局限的事。没有就删。】

## 产物

- 【运行目录/输出目录：脚本、开工/收尾指纹、进度日志、闸门结果、各表】
- 【结果说明：开头写身份；页数、条数、图数与均值、合计、占比等计数和派生数一律由脚本生成并留命令，不手抄或心算；写作卡只引用权威层已有的数，要新数回主控开计算卡】
- 【若要改权威文档：只写草案，不直接改】

## 不做的事

- 不改【原始数据 / 已有运行目录 / 口径 / 正文】
- 不改 🔒 节；不事后加说法
- 【本卡范围外的事。收口后想加的新计算另开卡，不加进本卡】

## 注意

- 环境：【解释器完整路径、必要环境变量】
- 临时文件只放【路径】，收工只清自己的子目录
- 已知坑：共性环境与软件坑见 `文档/环境坑.md`（卡面只链接不复述）；本卡特有坑：【编码、单位、坐标系等，写明出处】
- 【建议（目标＋底线卡）：执行方可参考的调整或分析方向；新分析只建议不执行；没有就删】

## 收口方式

执行方交回 → 用户派独立复核（与执行方不同 agent；论文结论/头条数字类须不同模型家族，复核方自己重算；主控只按复核报告“会出错”节触发返工）→ 主控执行“收口三查”（见 `任务卡_README.md`）、登记决策。复核通过前产物标“待验”，下游不得启用。【合入权威文档签核用 `任务卡_README.md` 的例行签核提示词，不在本卡加新提示词。】
