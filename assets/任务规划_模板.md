  > ⚠️ **两条硬要求（实测数据支撑，别删）**：
  > 1. **块内第一行的字段清单注释必须随块复制**。建新卡时人和 agent 抄的都是**邻居那张卡**，不会回头翻本模板——字段清单只写在模板里，复制到第二张卡就蒸发。实测某项目 155 张卡：约 125 张有派发块（**自发传播得极好，说明这设计对**），但**没有一张字段齐全**——『已知坑』13%、『交付前自查』28%、『输入(精确路径)』11%；其中 70 张只有 📋 标题、连代码围栏都没有，"复制即用"无从谈起。**传播的是形状，丢的是规范——能自我复制的东西必须能自我说明。**
  > 2. **`完事后` 只写指针，不复述收工步骤**。收工规矩的唯一真相在 AGENTS.md §5；每张卡复述一遍＝制造 N 份副本，必然与 §5 漂移——这正是本 skill 规则 6「别处只引用不复述」禁止的事。实测：本块曾硬写"跑 python scripts/check_handoff.py"，而某项目 §5 定的是"chatmem checkpoint"，两套仪式打架；agent 照 §5 执行（**agent 是对的**——本 skill 命令它进门先读 AGENTS.md），本块那句的遵守率只有 **1.6%（2/123）**。**不是 agent 不听话，是模板违反了原则 §1「真相只有一份」。**
  >
  > 📏 **加字段前先量一量**：本块字段已达 10 个，而实测填充率天花板约 **3.4 个**。新字段进块前，先确认它在真实卡里已经自发出现过——派发块本身就是这么来的（先在 125/155 张卡里长出来，才被固化）。
