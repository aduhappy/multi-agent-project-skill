# 任务卡目录索引

> 新 agent 进来不知道先做哪张卡？看这里。本文件列依赖链、当前状态，并且是**卡面规矩的唯一出处**。
> 单张任务卡细节看对应的 `.md` 文件；全量看板看 AGENTS.md §4。
> 🔴 一个任务一张卡：执行和独立复核在同一张卡里，复核**不单列一行**。

## 依赖链（谁依赖谁，可并行哪些）

```

        ↘
T3 ─────→ T5 → T6（T3 与 T2 可并行）
```

|---|---|---|---|---|

> **新 agent 找活干**：状态列找第一个 ⬜，检查它的依赖是否都 ✅，再打开卡确认“进度回写”仍是 ⬜，是→开干。
> **命名约定**：任务卡文件名 `T<编号>_<简短主题>.md`，如 `T1_数据清洗.md`。

## 卡面规矩（主控出卡、改卡时照做）

**谁改卡面哪里**

| 位置 | 执行方 | 复核方 | 主控 |
|:--|:--|:--|:--|
| 卡面“进度回写” | 自己那一行；⬜→⏳（开工）、⏳→🟡（交回） | 自己那一行；🟡→🔵（交回报告） | 主控行；✅ / ⛔ / 🗄️ / 🟠 |
| 卡面其余各节 | 不改，有错停下报告 | 不改 | 就地改，记变更记录 |
| `STATUS.md` 交接段 | 追加 | 追加 | 追加 |
| `AGENTS.md` 任何一节，本索引 | 不改 | 不改 | §3、§3.5、§4 与本索引在派发、收口时同步；对不上以卡面为准（检查器 A007、A008 提示） |

没有主控的单 agent 项目，由该 agent 兼任主控那一列。主控不替用户派执行方、复核方（含子代理），用户点名除外。

**别让卡越写越大**

1. 🔒 节（定义、判据、阈值、措辞红线）写死：只许补澄清（标日期、决策 ID，不改值）；要改值就登记新决策、开新卡。
2. 其余各节（输入指纹、产物、注意、提示词）由主控**就地改成最新**；每改一次在卡末“变更记录”记一行（日期｜决策 ID｜改了哪节｜为什么）。不在卡末追加“主控补充”“以本节为准”——那样新 agent 得自己把五六节拼成现状。答执行方的问题，把答案写回对应的节。
3. 同时有效的派发提示词只留**执行、复核两段**（同一任务多路并派时每路一段）。返修就把这两段就地改成返修版；用过的提示词在收口时删掉，变更记录留一行。
4. 下面几种情况**开新卡**，新卡开头写“接 Tx”，旧卡进度回写写“由 Ty 接续”：
   - 要改 🔒 节的值；
   - 原做法作废、要换做法重跑；
   - 收口后想再加一项计算或分析；
   - 下一步是另一类活（合入权威文档、改正文、出图）；
   - 多步串行、每步换人且中间要主控裁定（卡号加 a、b）。
5. 收口时瘦身：主控行一两句结论，细节进 STATUS 和决策记录；删用过的提示词。
   只差措辞时可以不退回（可选）：数值经独立复算复现、只改措辞或解读、不改判读档位，主控可在执行方结果说明末尾追加“主控收口附注”（注明交回版 SHA、以附注为准）；改了数或判读档位就照常 ⛔ 退回。
6. 体积线：卡 ≤15KB、提示词段 ≤3（标题带 📋 或“提示词”的都算一段，检查器 A006 提示；提示词标题一律以 📋 开头）；本索引 ≤15KB（A003）。超了先看是不是该拆卡。

## 例行签核提示词（合入权威文档后用；卡里只写参数，不另加提示词）

````text
请作为【卡号】合入签核方，核对主控合入【权威文档路径】的【新增段，例：§十二】。你与写这段的 agent 同家族就停下告诉我。
先读：AGENTS.md，任务卡【路径】的“进度回写”和“主控收口”，复核报告【路径】，草案【路径】。
只读。要查：1）合入前的部分是否没动（主控给的前缀字节数与 SHA-256：【值】）；2）新增段与草案、复核后的订正是否一致，每个数能否在产物表里找到；3）措辞有没有越过卡面 🔒 措辞。
报告写到【文档/<卡号>_合入签核_<模型名>_<日期>.md】，开头写身份和结论（通过／有条件通过／不通过），分“必须改”“建议改”。在 STATUS.md 末尾追加交接段，不改其他文件。
做完用几句大白话告诉我：能不能引用、有没有对不上的地方。
````

## 当前推荐入口

- **如果从零接手**：从第一个 ⬜ 的任务开始，往前读它的依赖任务的卡。
- **如果接上一个 agent 的棒**：先读 STATUS.md（增量 handoff），再读 AGENTS.md §3（累计快照），最后定位到当前任务的卡。
